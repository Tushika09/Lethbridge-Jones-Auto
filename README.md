## Lethbridge Jones Auto

A database management system developed for a used-car dealership using PHP, MySQL, SQL, and HTML. The system was designed to manage information related to vehicles, customers, employees, sales, purchases, warranties, payments, and vehicle repairs.

## Project Overview

This project was completed as part of **CPSC 3660 – Database Systems** at the University of Lethbridge.

The main objective of the project was to design and implement a relational database for a used-car dealership. The system allows users to enter, manage, and retrieve dealership information through database forms and reports.

## Technologies Used

* PHP
* MySQL
* SQL
* HTML
* XAMPP

## Main Features

The system includes functionality for:

* Managing customer and employee information
* Managing vehicle information and inventory
* Recording vehicle purchases and sales
* Managing warranties
* Recording and tracking payments
* Recording vehicle problems and repair costs
* Generating database reports
* Retrieving information using SQL queries involving multiple tables
* Calculating financial information such as:

  * Sale Profit
  * Paid to Date
  * Total Cost
  * Unpaid Payments
